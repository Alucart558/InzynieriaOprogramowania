# Inżynieria Oprogramowania

## Opis Projektu

Projekt związany z inżynierią oprogramowania zawierający diagramy UML i dokumentację architektoniczną.

## Zawartość Repozytorium

- **Inzynieria.drawio** - Diagram UML projektu
- **WizjaUMLv1.drawio** - Wizja architektury UML v1
- **Untitled Diagram.drawio** - Dodatkowe diagramy

## O Projekcie

Repozytorium zawiera:
- Diagramy UML dla modelowania systemu
- Dokumentację architektoniczną
- Pliki projektowe

## Jak Korzystać

1. Pobierz pliki `.drawio`
2. Otwórz je w aplikacji [draw.io](https://draw.io)
3. Przejrzyj i edytuj diagramy
